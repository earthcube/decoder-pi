# Database Migration Skill

## Blocking Pre-Conditions
Before modifying any schema file in src/db/:
1. Run "npm run db:check" to verify the current migration state.
2. Confirm that no pending unapplied migrations exist in src/db/migrations/.

## Execution Rules
- Always use Drizzle Kit generate commands rather than hand-writing raw SQL migrations.
- If altering a non-null column, provide an explicit default value to prevent table locks.
- Never run dropTable without an explicit dry-run confirmation from the user.

## Verification Gate (Mandatory)
Run the following verification sequence in order:
1. Run "npm run db:generate" to generate migration files.
2. Run "npm run test:db" to execute the migration test suite against local Postgres.
3. If exit code != 0, inspect the migration log, revert the change, and apply the Smallest Durable Fix.
